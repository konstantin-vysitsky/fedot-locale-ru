# Русский язык для DeepSeek Harness

Версия пакета: 0.1.2
Отметка архива: 10.11.2026, 23:50

Пакет ставит русский язык интерфейса DeepSeek Harness. 59 пространств имён,
2546 ключей: кнопки, меню, настройки, подписи разделов.

Здесь лежит **только собранный пакет**. Исходники живут отдельно и в этот
репозиторий не попадают.

## Установка

Требуется DeepSeek Harness `0.2.2-rc.1`. Более старые версии (0.2.1) пакет
не обновят — новые строки интерфейса там ещё не появились, часть подписей
останется английской.

Архив: **fedot-locale-ru-0.1.2.tgz** (доступен отдельным файлом — сайт сейчас
недоступен, архив передаётся напрямую).

1. Запомните, куда попал архив (обычно «Загрузки»).
2. Запустите Harness.
3. На панели слева, под **«Новой сессией»**, нажмите кнопку **«Плагины»**
   (на ней элемент пазла). Это не «Настройки» — раздел живёт на боковой панели.
4. Нажмите **«Добавить плагин»** и укажите **путь к скачанному файлу**:

   ```
   C:\Users\<имя>\Downloads\fedot-locale-ru-0.1.2.tgz
   ```

   Именно путь к файлу на диске, а не адрес сайта. Распаковывать архив не нужно.
5. Нажмите **«Установить»** и перезапустите приложение.

Интерфейс станет русским. Своих настроек у пакета нет — он только переводит.

Если в списке плагинов после установки ничего не появилось, проверьте, что
установился именно этот архив: в нём должны быть `cordis.patch.yml` и поле
`dsh.bundle` в `package.json`. Без них установка проходит молча, но плагин
не включается.

### Почему архив, а не ссылка на GitHub

Раньше в этом месте была ссылка на репозиторий. Она требует установленного
**git**: менеджер плагинов спрашивает у GitHub ссылки на ветки командой
`git ls-remote`, и там, где git нет, установка обрывается на первой же ошибке.

```
[ERROR] Command failed with exit code 1: git ls-remote "https://github.com/..."
"git" не является внутренней или внешней командой
```

Архив этого не требует: ни git, ни доступа к GitHub. Если вы всё же ставите из
GitHub и видите такую ошибку — установите
[Git для Windows](https://git-scm.com/download/win) и **перезапустите
приложение**, иначе новый путь к программе не подхватится.

## Что внутри

| Файл | Что это |
|---|---|
| `lib/index.js` | хост-половина: ничего не делает, нужна для загрузки пакета |
| `lib/client.js` | браузерная половина: словари 59 пространств имён |
| `cordis.patch.yml` | слой, который вставляет пакет в дерево конфигурации |

Поле `dsh.bundle` в `package.json` делает пакет полноценным слоем. Благодаря
ему пакет ставится сам по себе, без общего сборочного слоя.

## Что нового в 0.1.2

Перевод приведён к интерфейсу DeepSeek Harness 0.2.2-rc.1:

- три словаря, которых в 0.2.2 больше нет, убраны: «Режимы доступа» (окно
  уровней прав), «Автоматизации» (экран задач по расписанию) и подпись модели
  «1017»;
- четыре новых словаря переведены целиком: меню «Открыть в…», действия с
  файлами, перетаскивание файла, цитаты в сообщениях;
- добавлено 155 новых строк: обновление плагинов и выбор версии, «Открыть на
  боковой панели / в плавающей панели», сворачиваемые ответы ассистента,
  частоты автоматизаций, вложенные вызовы в «Траектории» и другие;
- 26 изменившихся строк переписаны, 214 устаревших удалены;
- весь текст в одном тоне (вежливое «вы»), как в прежней версии пакета.

## Ограничения

- **Версия привязана к харнессу.** Пакет объявляет совместимость с
  `0.2.2-rc.1` (зависимость `@deepseek-ai/cordis ~4.1.0`). На 0.2.1-rc.x
  интерфейс переведётся не полностью — новых строк там нет.
- **Переводится интерфейс, но не шелл.** Меню, окно «О программе» и диалоги
  обновления рисует Electron-оболочка, у неё свой закрытый словарь. Эти строки
  остаются английскими и китайскими.
- **Описания пакетов в каталоге плагинов не переводятся.** Они лежат в файлах
  `locale/en.json` рядом с чужими пакетами, и харнесс читает их отдельно.
- **Обновления автоматом не приходят.** Чтобы поставить новую версию, пакет
  надо удалить и установить заново: архив передаётся файлом.

## Сборка

Файлы в `lib/` собраны из исходников (словари `packages/locale-ru`) скриптом
`scripts/build.mjs` в рабочем репозитории модулей. Здесь они лежат готовыми:
так ученику не нужны ни Node, ни pnpm, ни TypeScript.

Архив `fedot-locale-ru-0.1.2.tgz` собирается из этого каталога командой
`pnpm pack` и на витрине лежит по адресу
`token-seller/static/plugins/fedot-locale-ru-0.1.2.tgz`. После обновления файлов
в `lib/` архив нужно собрать заново и положить на витрину — иначе со страницы
установки по-прежнему будет скачиваться старая сборка.

## Каталог `словари-0.2.2`

Снимок всех 59 словарей, которые вошли в сборку 0.1.2 (для харнесса
0.2.2-rc.1): по одному файлу `lib/client.js` на пространство имён, формат —
`export default { 'ключ': 'перевод' }`. Положены сюда, чтобы перевод не жил
только в рабочем репозитории модулей: сеть и витрина бывают недоступны.

Как из них пересобрать `lib/client.js`:

1. положить файлы в `<fedot-modules>/packages/locale-ru/src/client/locales/`
   (заменив прежние);
2. `node scripts/build-locale-index.mjs` — пересоберёт
   `src/client/dictionaries.ts`;
3. `node scripts/build.mjs --package locale-ru` — соберёт `lib/client.js`;
4. `pnpm pack` из этого каталога — архив.

Расхождение, которое надо знать: в сборку 0.1.2 вошли `chat`, `conversation`,
`deliverables` и `subagent` **из релиза 0.1.1** (их же строки остались и здесь) —
исходного кода для их повторной сборки в момент выпуска не было. Остальные 55
словарей собраны и сверены с английскими один в один: 2546 ключей на 59
пространств имён, подстановки `{...}` на месте.
