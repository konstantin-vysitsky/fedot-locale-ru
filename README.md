# Русский язык для DeepSeek Harness

Пакет ставит русский язык интерфейса DeepSeek Harness. 58 пространств имён,
около 2500 ключей: кнопки, меню, настройки, подписи разделов.

Здесь лежит **только собранный пакет**. Исходники живут отдельно и в этот
репозиторий не попадают.

## Установка

Требуется DeepSeek Harness `0.2.0-rc.2`.

1. Запустите Harness.
2. Откройте **Настройки** → **Plugins**.
3. Нажмите **Add plugin**.
4. Вставьте адрес репозитория:

   ```
   https://github.com/konstantin-vysitsky/fedot-locale-ru
   ```

5. Нажмите **Install** и перезапустите приложение.

Интерфейс станет русским. Своих настроек у пакета нет — он только переводит.

> **Имя репозитория уточните у автора.** Если репозиторий назван иначе, адрес
> в пункте 4 будет другим: имя в адресе должно совпадать с именем на GitHub.

### Установка из командной строки

То же самое без интерфейса, если удобнее:

```powershell
dsh plugin --profile desktop add "https://github.com/konstantin-vysitsky/fedot-locale-ru"
```

Профиль `desktop` принадлежит приложению, и командная строка его не примет.
Команда выше подходит для профиля, созданного вами; в приложении пользуйтесь
кнопкой **Add plugin**.

## Что внутри

| Файл | Что это |
|---|---|
| `lib/index.js` | хост-половина: ничего не делает, нужна для загрузки пакета |
| `lib/client.js` | браузерная половина: словари 58 пространств имён |
| `cordis.patch.yml` | слой, который вставляет пакет в дерево конфигурации |

Поле `dsh.bundle` в `package.json` делает пакет полноценным слоем. Благодаря
ему пакет ставится сам по себе, без общего сборочного слоя.

## Ограничения

- **Версия привязана к харнессу.** Пакет объявляет совместимость с
  `0.2.0-rc.2`. На другой версии Harness откажет в установке.
- **Переводится интерфейс, но не шелл.** Меню, окно «О программе» и диалоги
  обновления рисует Electron-оболочка, у неё свой закрытый словарь. Эти строки
  остаются английскими и китайскими.
- **Описания пакетов в каталоге плагинов не переводятся.** Они лежат в файлах
  `locale/en.json` рядом с чужими пакетами, и харнесс читает их отдельно.
- **Обновления автоматом не приходят.** Чтобы поставить новую версию, пакет
  надо удалить и установить заново.

## Сборка

Файлы в `lib/` собраны из исходников скриптом `scripts/build.mjs` в рабочем
репозитории модулей. Здесь они лежат готовыми: так ученику не нужны ни Node,
ни pnpm, ни TypeScript.
