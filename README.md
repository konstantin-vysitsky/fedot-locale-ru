# Русский язык для DeepSeek Harness

Пакет ставит русский язык интерфейса DeepSeek Harness. 58 пространств имён,
около 2500 ключей: кнопки, меню, настройки, подписи разделов.

Здесь лежит **только собранный пакет**. Исходники живут отдельно и в этот
репозиторий не попадают.

## Установка

Требуется DeepSeek Harness `0.2.0-rc.2`.

Готовый архив: **https://федота.рф/download/plugins/fedot-locale-ru-0.1.0.tgz**

1. Скачайте архив по ссылке выше и запомните, куда он попал (обычно «Загрузки»).
2. Запустите Harness.
3. На панели слева, под **«Новой сессией»**, нажмите кнопку **«Плагины»**
   (на ней элемент пазла). Это не «Настройки» — раздел живёт на боковой панели.
4. Нажмите **«Добавить плагин»** и укажите **путь к скачанному файлу**:

   ```
   C:\Users\<имя>\Downloads\fedot-locale-ru-0.1.0.tgz
   ```

   Именно путь к файлу на диске, а не адрес сайта. Распаковывать архив не нужно.
5. Нажмите **«Установить»** и перезапустите приложение.

Интерфейс станет русским. Своих настроек у пакета нет — он только переводит.

Если в списке плагинов после установки ничего не появилось, проверьте, что
установился именно этот архив: в нём должны быть `cordis.patch.yml` и поле
`dsh.bundle` в `package.json`. Без них установка проходит молча, но плагин
не включается.

### Почему архив, а не ссылка на GitHub

Раньше в этом месте была ссылка на репозиторий. Она требует установленного
**git**: менеджер плагинов спрашивает у GitHub ссылки на ветки командой
`git ls-remote`, и там, где git нет, установка обрывается на первой же ошибке.

```
[ERROR] Command failed with exit code 1: git ls-remote "https://github.com/..."
"git" не является внутренней или внешней командой
```

Архив этого не требует: ни git, ни доступа к GitHub. Если вы всё же ставите из
GitHub и видите такую ошибку — установите
[Git для Windows](https://git-scm.com/download/win) и **перезапустите
приложение**, иначе новый путь к программе не подхватится.

### Установка из командной строки

То же самое без интерфейса, если удобнее:

```powershell
dsh plugin --profile <профиль> add "C:\Users\<имя>\Downloads\fedot-locale-ru-0.1.0.tgz"
```

Профиль `desktop` принадлежит приложению, и командная строка его не примет.
Команда выше подходит для профиля, созданного вами; в приложении пользуйтесь
кнопкой **«Добавить плагин»**.

## Что внутри

| Файл | Что это |
|---|---|
| `lib/index.js` | хост-половина: ничего не делает, нужна для загрузки пакета |
| `lib/client.js` | браузерная половина: словари 58 пространств имён |
| `cordis.patch.yml` | слой, который вставляет пакет в дерево конфигурации |

Поле `dsh.bundle` в `package.json` делает пакет полноценным слоем. Благодаря
ему пакет ставится сам по себе, без общего сборочного слоя.

## Ограничения

- **Версия привязана к харнессу.** Пакет объявляет совместимость с
  `0.2.0-rc.2`. На другой версии Harness откажет в установке.
- **Переводится интерфейс, но не шелл.** Меню, окно «О программе» и диалоги
  обновления рисует Electron-оболочка, у неё свой закрытый словарь. Эти строки
  остаются английскими и китайскими.
- **Описания пакетов в каталоге плагинов не переводятся.** Они лежат в файлах
  `locale/en.json` рядом с чужими пакетами, и харнесс читает их отдельно.
- **Обновления автоматом не приходят.** Чтобы поставить новую версию, пакет
  надо удалить и установить заново: свежий архив берётся по той же ссылке.

## Сборка

Файлы в `lib/` собраны из исходников скриптом `scripts/build.mjs` в рабочем
репозитории модулей. Здесь они лежат готовыми: так ученику не нужны ни Node,
ни pnpm, ни TypeScript.

Архив `fedot-locale-ru-0.1.0.tgz` собирается из этого каталога командой
`pnpm pack` и лежит на витрине по адресу
`token-seller/static/plugins/fedot-locale-ru-0.1.0.tgz`. После обновления файлов
в `lib/` архив нужно собрать заново и положить на витрину — иначе со страницы
установки по-прежнему будет скачиваться старая сборка.
